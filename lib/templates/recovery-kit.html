If you lose your password

  1. Open {{APP_NAME}} and choose this vault, or from a terminal run {{CLI}} mount "{{VAULT_PATH}}".
  2. When asked for the password, enter the recovery key above instead.
  3. Once the vault opens, set a new password you will remember ({{CLI}} passwd "{{VAULT_PATH}}"), then create a fresh kit so your spare key is new again.
Lost the whole folder too? If you set up a mirror, a backup, or split the vault across several places, restore the encrypted folder first, then follow the steps above. The identity code lets you confirm the restored vault is really yours before you trust it.
